# Filosofia

O Nexa deve transmitir calma e organização.

O estudante nunca deve sentir que está sendo cobrado.

A plataforma deve agir como uma guia da rotina escolar.

Cada tela deve responder uma pergunta:

Hoje → O que fazer agora?

Dashboard → Como estou?

Disciplinas → O que sei?

Agenda → O que vem pela frente?

Desempenho → Estou evoluindo?

Perfil → Quem sou e quais são minhas metas?

# Objetivo Final

Construir uma plataforma escalável, moderna e intuitiva, capaz de
atender inicialmente um único estudante e evoluir para um SaaS
educacional com milhares de usuários, mantendo excelente experiência de
uso, arquitetura sólida e alta qualidade visual.
