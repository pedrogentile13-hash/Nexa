# Nexa

> **Your Academic Operating System.**

Nexa é uma plataforma moderna de gestão acadêmica desenvolvida para
ajudar estudantes a organizarem sua rotina escolar, acompanharem seu
desempenho, planejarem estudos e conquistarem melhores resultados
através de organização, disciplina e constância.

## Missão

Transformar a vida acadêmica dos estudantes através da organização,
clareza e acompanhamento diário.

## Visão

Ser a plataforma de organização acadêmica mais completa para estudantes
do Ensino Fundamental II, Ensino Médio e Vestibulares.

## Valores

- Simplicidade
- Organização
- Consistência
- Evolução contínua
- Design intuitivo
- Experiência agradável
- Tecnologia a favor da educação

## Problema

Grande parte dos estudantes: - não sabem exatamente o que estudar; -
estudam apenas antes das provas; - esquecem tarefas; - não acompanham
suas notas; - não possuem rotina; - não conseguem visualizar sua
evolução.

O Nexa resolve esse problema centralizando toda a vida acadêmica em um
único lugar.

## Objetivo do Produto

O Nexa não é apenas um aplicativo de estudos.

Ele é um sistema operacional da vida escolar.

Perguntas que ele responde: - O que estudar hoje? - Qual minha média? -
Tenho prova amanhã? - Quanto falta para alcançar média 8? - Qual matéria
precisa de mais atenção? - Quanto estudei nesta semana?

## Público-alvo

Inicialmente: - Ensino Fundamental II

Futuro: - Ensino Médio - Pré-vestibular - Universidades

# Disciplinas

Cada disciplina possui: - Resumos - Arquivos - Exercícios - Avaliações -
Notas - Calendário - Estatísticas

Disciplinas padrão: - Artes - Biologia - Educação Financeira - Educação
Física - Educação Socioemocional - Física - Geografia - História -
Inglês - Iniciação Científica - Língua Portuguesa - Matemática -
Pensamento Computacional - Produção de Texto - Química

As disciplinas nunca serão fixas no código.

# Sistema de Avaliações

Categorias padrão: - PB (35%) - VA (35%) - Qualitativa (30%)

Os pesos poderão ser alterados.

# Sistema de Atividades

Cada categoria possui várias atividades.

Cada atividade possui: - Nome - Nota - Peso (0-10) - Data - Observações

O sistema calcula automaticamente: 1. Média da categoria 2. Média final
da disciplina

# Filosofia

O usuário nunca deve precisar pensar no próximo passo.

O Nexa deve sempre responder: **"O que preciso fazer agora?"**

Todo recurso deve existir para melhorar a organização, a constância e o
desempenho acadêmico.
